// CsWin32 manifest for the Taj bar.
//
// Window, message loop, monitors, DPI and the appbar reservation. The drawing
// imports live in Shubbak.Ui.Gdi with the renderer they belong to, so the bar owns
// the window and Shubbak.Ui.Gdi owns the pixels. BeginPaint and EndPaint stay here:
// they bracket WM_PAINT, which is the window's business, not the renderer's.
