// --- shell cloaking (undocumented) ------------------------------------------
// Deliberately absent. DWMWA_CLOAK is a per-process attribute - setting it on a
// window owned by another process returns E_ACCESSDENIED, so it can never conceal a
// window Shubbak manages. The shell's IApplicationView::SetCloak has no such
// restriction, but CsWin32 emits ComImport interfaces for COM types, which are not
// NativeAOT-safe. Those interfaces are therefore hand-rolled as raw vtable calls in
// Win32ApplicationView and Win32Taskbar, which also keeps them allocation-free.

//
// RegisterHotKey is not a hook: the system matches the chord itself and posts a

// reason suspending is worth having.

// --- the tray icon --------------------------------------------------------------
//
// The daemon's first and only window, and it is message-only: created with
// HWND_MESSAGE as its parent, so EnumWindows never returns it and Shubbak cannot
// end up trying to tile its own tray plumbing.
//
// Shell_NotifyIcon needs a window to send its callback message to, which is the
// entire reason any of this is here. TrackPopupMenu runs a modal loop while the
// menu is open - acceptable on this thread, which is not on the input path, and
// unacceptable on the keyboard hook's, which is why the tray lives here and not
// there.
