// CsWin32 manifest for the Dalil palette.
//
// Unlike the bar, this window takes the keyboard. That is the whole difference
// between the two manifests: WM_CHAR and WM_KEYDOWN to read it, SetForegroundWindow
// and SetFocus to get it, and WM_ACTIVATE to notice it has gone. The window class,
// the window procedure, painting brackets and the message loop live in
// Shubbak.Companion with the base class every companion window derives from.
//
// The drawing imports are not here. They live in Shubbak.Ui.Gdi with the renderer.

// --- window ---------------------------------------------------------------------

WINDOW_STYLE
WINDOW_EX_STYLE

// --- taking and losing the keyboard ------------------------------------------------
SetForegroundWindow

AttachThreadInput
GetWindowThreadProcessId
GetCurrentThreadId
IsWindow
WM_ACTIVATE
WM_CHAR
WM_KEYDOWN
WM_SYSKEYDOWN
GetKeyState
VIRTUAL_KEY

// The one event this process injects, ever: a key-up of a key nobody has bound and
// nobody is holding, so that Windows counts this process as having provided the last
// input and lets SetForegroundWindow through. See Foreground.
SendInput
INPUT
INPUT_TYPE
KEYBD_EVENT_FLAGS
